# dvOne
 dvOne is a unique bred of PHP framework, originating in 2005 and maintained until today. In dvOne you'll likely find not just one or two relics, but alot.  Designed to be extensible and expandable and supports for external and components.  This might be quirky.
 
 Designed with simplycity in mind, ease of deployment, easy customisation and extensibility in mind.  This project is proven and used by more than 1000 user. 
 
 This also support extra security using the dv1-auth project to store authentication passwords for database user and passwords to store on physically different server. 

 dvOne also support web service for integation with IOT via HTTP interface.
  
 Our motto is crude and powerful.  Crude, yes, powerful? Working on it.
 
 Please note
 To deploy you needs to change lib_includes.php, lib_main.php to whatever you needed.
 
 page.php image.php service.php leftmenu.php should work as standard.
